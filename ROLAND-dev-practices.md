How to use Simple Invoices and develop for upstrea on *different branches*

The master_2020 branch should always be identical (or at worst very nearly identical), to upstream code.

The redcuillin_2020 branch is my working copy, containing customizations of code that are useful to me.

Any coding that is intended to be provided to upstream fearless359/simpleinvoices should be done in a NEW Branch forked from master_2020, so that it can be easily pulled and merged.
